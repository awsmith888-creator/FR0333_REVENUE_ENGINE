# FR-0333 Legal / IP Readiness Gate 0001

## Boundary
This record supports private ownership documentation and legal-readiness review. It is not legal advice, an accredited certification, a patent grant, a copyright registration, a trademark registration, or a finding of legal compliance.

## Ownership evidence package
Preserve author/operator identity records, dated source files, Git history, immutable hashes, design notebooks, specification lineage, contributor assignments/licenses, third-party license inventory, and release receipts. Private ownership is asserted only to the extent supported by those records and applicable law.

## U.S. IP separation
- COPYRIGHT: protectable original expression in source code and documentation may qualify; ideas, systems, methods, program logic, concepts, and algorithms as such are not protected by copyright.
- TRADEMARK: names/logos/source identifiers require separate clearance and, when desired, registration strategy.
- PATENT: potentially patentable inventions require novelty/non-obviousness/eligibility analysis and filing strategy before public disclosure where timing matters.
- TRADE SECRET: nonpublic architecture, thresholds, credentials, methods, and mappings require reasonable secrecy controls, access limitation, confidentiality terms, and disclosure logging.
- CONTRACT/LICENSE: every external model, dataset, library, API, artifact, and contributor input must have recorded terms and compatibility status.

## Required legal-use records before L3 can PASS
1. Jurisdiction and deployment/use-case statement.
2. Data inventory and privacy basis/retention/access/deletion review.
3. Security threat model, SBOM/dependency review, secrets handling, access control, incident response, penetration/abuse testing evidence.
4. IP/license provenance ledger and contributor-rights record.
5. Capability/accuracy representation review; no unsupported 100% truth/security/reliability claim.
6. Sector-specific review when used in regulated/high-impact domains.
7. Contracts, vendor terms, DPAs, warranties/indemnities/insurance as applicable.
8. Qualified legal review where required by the deployment context.
